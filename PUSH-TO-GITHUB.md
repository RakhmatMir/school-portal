# Публикация на GitHub

Если репозиторий ещё не создан:

1. https://github.com/new → имя **`school-portal`** → описание «Школьный портал» → **Create repository** (без README).
2. В терминале:

```bash
cd school-portal
git remote add origin https://github.com/RakhmatMir/school-portal.git
git push -u origin main
```

Репозиторий **не связан** с quiz-bot.
