# Запуск сайта

**https://rakhmatmir.github.io/school-portal/** (не корень `github.io`).

Если 404: **Settings → Pages → GitHub Actions**, затем **Actions → Deploy GitHub Pages → Run workflow**.

Данные и вход: **`data/portal.json`**. Ученики 6Б: логины `6b01`–`6b19`, у каждого свой пароль (таблица в `data/6b-student-logins.txt`). Учитель: `teacher` / `teacher123`. Админ: `admin` / `admin123`.
