# data/portal.json — все данные демо-портала

Один файл для правок на GitHub. После изменения — commit и push в `main` (через 1–2 минуты обновится сайт на Pages).

## Основные поля

| Поле | Назначение |
|------|------------|
| `school_name` | Название на экране входа |
| `classes` | Список классов (админка) |
| `subjects` | Предметы |
| `exams` | Тесты и контрольные (+ `questions` внутри каждого) |
| `rosters` | Ученики класса (для аналитики учителя) |
| `demo_users` | **Вход на сайт** — login, password, role, full_name, class_name, id |
| `demo_exam_answers` | Примеры ответов для демо-аналитики |
| `demo_question_times` | Секунды на каждый вопрос (`exam_id:student_id` → массив), усредняются в аналитике |
| `demo_question_exit_counts` | Выходы из вкладки на каждом вопросе |
| `demo_question_away_seconds` | Секунды вне вкладки на каждом вопросе |

Пока не сдали **все** ученики из `rosters` для класса экзамена, оценки и аналитика скрыты; после последней сдачи результаты открываются сразу у учеников и у учителя.

## Добавить ученика для входа

В `demo_users` добавьте объект:

```json
{
  "id": 10,
  "login": "student2",
  "password": "demo",
  "full_name": "Имя Фамилия",
  "role": "student",
  "class_name": "6Б"
}
```

Роли: `admin`, `teacher`, `student`.

## Класс 6Б (19 учеников)

Полный список логинов: [`6b-student-logins.txt`](6b-student-logins.txt).

- Логины: `6b01` … `6b19`
- Пароль **у каждого свой**: `6b01-401`, `6b02-402`, … `6b19-419` (см. таблицу в файле)
- В портале только класс **6Б**; сейчас один тест — **английский A1** (Tursunova Barno, 10 вопросов). Результаты открываются, когда сдадут **все 19** из `rosters["6Б"]`.

## Безопасность

Это **тестовый** стенд: пароли в JSON видны всем. Для реальной школы нужен другой backend — не этот режим.
