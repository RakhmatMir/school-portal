# data/portal.json — все данные демо-портала

Один файл для правок на GitHub. После изменения — commit и push в `main` (через 1–2 минуты обновится сайт на Pages).

## Основные поля

| Поле | Назначение |
|------|------------|
| `school_name` | Название на экране входа |
| `classes` | Список классов (админка) |
| `subjects` | Предметы |
| `exams` | Тесты и контрольные (+ `questions` внутри каждого) |
| `rosters` | Ученики класса (для аналитики учителя) |
| `demo_users` | **Вход на сайт** — login, password, role, full_name, class_name, id |
| `demo_exam_answers` | Примеры ответов для демо-аналитики |
| `demo_question_times` | Секунды на каждый вопрос (`exam_id:student_id` → массив), усредняются в аналитике |
| `demo_question_exit_counts` | Выходы из вкладки на каждом вопросе |
| `demo_question_away_seconds` | Секунды вне вкладки на каждом вопросе |

Пока не сдали **все** ученики из `rosters` для класса экзамена, оценки и аналитика скрыты; после последней сдачи результаты открываются сразу у учеников и у учителя.

Учитель на странице теста может **править вопросы** и **опубликовать** их ученикам. Черновик и публикация хранятся в `localStorage` браузера (на одном компьютере/планшете в классе — общий профиль; для всех устройств после правок обновите `portal.json` в репозитории).

## Добавить ученика для входа

В `demo_users` добавьте объект:

```json
{
  "id": 10,
  "login": "student2",
  "password": "demo",
  "full_name": "Имя Фамилия",
  "role": "student",
  "class_name": "6Б"
}
```

Роли: `admin`, `student`.

## Сброс сдач при проверке сайта (не для учеников)

Ответы учеников на GitHub Pages лежат в браузере: ключ `portal_site_submissions_v1`. В интерфейсе повторная сдача отключена. Для своих тестов: откройте сайт с параметром `?portal_dev=clear` (один раз), либо в консоли `localStorage.removeItem('portal_site_submissions_v1')` и обновите страницу.

Публикация тестов для класса задаётся в `portal.json` → `class_schedules` (чтобы ученики на любых устройствах видели тесты без действий админа в их браузере).

Чтобы у ученика не было сдач в браузере (демо), добавьте его `id` в `cleared_student_ids` — при загрузке сайта его ключи в `portal_site_submissions_v1` удаляются автоматически.

## Класс 6Б (18 учеников)

Полный список логинов: [`6b-student-logins.txt`](6b-student-logins.txt).

- Логины: `6b02` … `6b19`
- Пароль **у каждого свой**: `6b02-402`, … `6b19-419` (см. таблицу в файле)
- В портале только класс **6Б**; сейчас один тест — **английский A1** (Tursunova Barno, 10 вопросов). Результаты открываются, когда сдадут **все 18** из `rosters["6Б"]`.

## Безопасность

Это **тестовый** стенд: пароли в JSON видны всем. Для реальной школы нужен другой backend — не этот режим.
