# Школьный портал на Google Таблице

Таблица: https://docs.google.com/spreadsheets/d/1R7IwEg0gmvBnGal8oswynX6AdTTmGwezjx10BFWvHuw/edit

## 1. Установка скрипта (5–10 мин)

1. Откройте таблицу **«Школьный портал»**.
2. **Расширения → Apps Script**.
3. Удалите содержимое файла `Code.gs`.
4. Скопируйте **весь** текст из репозитория:
   - `google-sheets/Code.gs` → вставьте в `Code.gs`
   - **Файл → Создать → HTML** → имя `WebApp` → вставьте `google-sheets/WebApp.html`
5. Нажмите **Сохранить** (диск).
6. В выпадающем списке функций выберите **`initializeSheets`** → **Выполнить**.
   - Первый раз: **Разрешить доступ** к таблице (Advanced → Go to … → Allow).
   - Должно появиться сообщение «Листы готовы».
7. В таблице появятся листы `users`, `config`, `classes` и тестовые логины.

## 2. Публикация сайта (постоянная ссылка)

1. Apps Script → **Развернуть → Новое развёртывание**.
2. Тип: **Веб-приложение**.
3. **Выполнять от имени:** Я  
4. **У кого есть доступ:** Все  
5. **Развернуть** → скопируйте **URL веб-приложения**.

Это **ссылка для учеников и админов** (мессенджер, браузер). Туннель не нужен.

При изменении кода: **Развернуть → Управление развёртываниями → карандаш → Новая версия → Развернуть**.

## 3. Демо-логины (после initializeSheets)

| Логин | Пароль | Роль |
|-------|--------|------|
| admin | admin123 | admin |
| teacher | teacher123 | teacher |
| student1 | student123 | student (класс 6Б) |

## 4. Редактирование данных

- **users** — логин, пароль, роль (`admin` / `teacher` / `student`), ФИО, класс.
- **config** — название школы (`school_name`).
- **classes** — список классов для админки.

## 5. Безопасность

Сейчас пароли в таблице **открытым текстом** (удобно для демо). Для реальной школы позже: отдельные пароли, доступ «только вы» к таблице (Web App всё равно работает от вашего имени).
