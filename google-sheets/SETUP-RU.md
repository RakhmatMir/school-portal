# Школьный портал на Google Таблице (постоянная ссылка)

Таблица: https://docs.google.com/spreadsheets/d/1R7IwEg0gmvBnGal8oswynX6AdTTmGwezjx10BFWvHuw/edit

После развёртывания сайт открывается по адресу вида  
`https://script.google.com/macros/s/…/exec` — **без туннеля**, как обычный веб-сайт.

---

## 1. Подготовка файлов в репозитории

Если меняли `static/css/portal.css` или `static/js/portal.js`, пересоберите вложения для Apps Script:

```bash
python3 google-sheets/build_gas_assets.py
```

Появятся (или обновятся) `google-sheets/PortalStyles.html` и `google-sheets/PortalScript.html`.

---

## 2. Установка в Apps Script (10–15 мин)

1. Откройте таблицу **«Школьный портал»**.
2. **Расширения → Apps Script**.
3. Файлы в проекте (создайте HTML-файлы с **точными** именами):

| Имя в Apps Script | Файл в репозитории |
|-------------------|-------------------|
| `Code.gs` | `google-sheets/Code.gs` |
| `WebApp` (HTML) | `google-sheets/WebApp.html` |
| `PortalStyles` (HTML) | `google-sheets/PortalStyles.html` |
| `PortalScript` (HTML) | `google-sheets/PortalScript.html` |

4. **Сохранить** (диск).
5. В списке функций выберите **`initializeSheets`** → **Выполнить**.
   - Первый раз: разрешите доступ к таблице.
   - Появятся листы с демо-данными (пользователи, классы, тесты, вопросы).
6. **Развернуть → Тестовые развёртывания** → **Установить** (или **Новое развёртывание**):
   - Тип: **Веб-приложение**
   - **Выполнять от имени:** Я
   - **У кого есть доступ:** Все
7. Скопируйте **URL веб-приложения** — это ссылка для учеников и учителей.

При изменении кода: снова скопируйте файлы → **Развернуть → Управление развёртываниями → карандаш → Новая версия → Развернуть**.

## 4. Листы таблицы

| Лист | Назначение |
|------|------------|
| `users` | id, логин, пароль, роль, ФИО, класс |
| `config` | `school_name` и другие настройки |
| `classes` | классы для админки |
| `subjects` | предметы |
| `exams` | контрольные / тесты |
| `exam_questions` | вопросы и варианты |
| `class_roster` | ученики класса (для аналитики) |
| `submissions` | сдачи тестов (заполняется сайтом) |
| `demo_exam_answers` | демо-ответы для аналитики |
| `teacher_reports` | отметки «отчёт отправлен» |

## 5. Локальный сервер (для разработки)

```bash
pip install -r requirements.txt
./run.sh
```

Тот же интерфейс, данные в памяти (`demo_data.py`), без Google.

---

## 6. Безопасность

Пароли в таблице сейчас **открытым текстом** (удобно для демо). Таблицу лучше оставить доступной только вам; Web App всё равно работает от вашего имени.
